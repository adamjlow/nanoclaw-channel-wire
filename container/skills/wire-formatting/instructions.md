## Wire formatting

When you reply in a Wire conversation (channel type `wire`), write in the Markdown subset Wire renders:
- **bold**, *italic*, ~~strike~~, `code`, fenced code blocks, `#` headings, lists, `>` quotes, and links.
- Single newlines are line breaks.

Wire does **not** render tables, images or HTML. Use lists or code blocks instead of tables, and send images as file attachments. A Wire message holds at most 8000 characters; keep replies well under that.
